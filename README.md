# จับคำ

เว็บแอปสุ่มคำสำหรับงานประกวด เปิดผ่านเว็บโฮสต์ที่ให้บริการ `index.html` และ `results.html` จากโดเมนเดียวกัน

## ใช้งาน

- เพิ่มคำทีละคำ หรือโหลดรายการจาก Excel `.xlsx`, `.xls` และ CSV โดยใส่หนึ่งคำต่อแถว
- กด **สุ่มคำถัดไป** หรือ **สุ่มเร็วเต็มจอ** เพื่อสุ่ม คำที่หยุดจะไปอยู่ในรายการใช้แล้ว
- เลือกจับเวลาเดินหน้าหรือถอยหลังได้ เวลาบันทึกใช้รูปแบบ `MM.SS.CC` (นาที.วินาที.เซนติวินาที)
- กด **ดูผลการสุ่ม** บนแถบด้านบนเพื่อสร้างลิงก์แชร์เฉพาะกิจกรรม คัดลอกส่งให้ผู้ชมได้ หน้ารายงานแสดงคำ ผู้ได้รับคำ เวลา และจำนวนคำที่เหลือ พร้อมปุ่มส่งออก Excel
- กรอกตัวอักษรประเภทและจำนวนลำดับ 1–14 ที่แผงด้านขวาก่อนสุ่ม เช่น `M` และ `14` ระบบเรียงผู้ได้รับคำเป็น M1–M14; กรอก `G` และ `14` เพื่อใช้ G1–G14 แล้วล็อกค่าเมื่อเริ่มสุ่มในรอบนั้น
- กด **เริ่มรอบใหม่** เพื่อเก็บรอบปัจจุบันเป็นประวัติ แล้วเริ่มรอบถัดไป ลิงก์ที่แชร์เปิดตัวเลือกให้สลับดูรอบที่ผ่านมาในกิจกรรมเดียวกันได้
- จัดการประวัติรอบเก่าจากแผง **ประวัติรอบที่ผ่านมา** บนหน้าหลักได้ ทั้งลบทีละรอบและล้างรอบเก่าทั้งหมด โดยรอบปัจจุบันจะยังอยู่
- ผลการสุ่มซิงก์ไปยัง Supabase เมื่อมีการสร้างลิงก์ ผู้ที่เปิดลิงก์จะเห็นรายการอัปเดตแบบเรียลไทม์ ส่วนคลังคำและการตั้งค่าบันทึกในเบราว์เซอร์นี้
- `supabase-config.js` ใช้ project URL และ publishable key สำหรับเบราว์เซอร์ ห้ามใส่ service role/secret key ในไฟล์หน้าเว็บ
- `supabase-setup.sql` สร้าง SQL schema เริ่มต้น, `supabase-round-history.sql` เพิ่มประวัติรอบ, `supabase-contestant-settings.sql` เพิ่มตัวอักษรประเภทกับจำนวนลำดับ และ `supabase-round-management.sql` เพิ่ม RPC สำหรับลบประวัติ โดยเปิด RLS และปิดสิทธิ์อ่านตารางโดยตรง การอ่าน/เขียน/ลบทำผ่าน RPC ที่ตรวจ share ID หรือ writer token
- ผู้ได้รับคำกำหนดตามตัวอักษรและจำนวนที่ตั้งไว้ เช่น `M` จำนวน 14 คนจะได้ M1–M14 หรือ `G` จำนวน 14 คนจะได้ G1–G14 ตามลำดับการสุ่มในรอบปัจจุบัน

## เผยแพร่เว็บ

วาง `index.html`, `results.html` และ `supabase-config.js` ไว้บนเว็บโฮสต์ HTTPS เดียวกัน ฐานข้อมูล Supabase ของโปรเจกต์ที่เชื่อมไว้มี schema และการตั้งค่าประเภทแล้ว หากย้ายไปโปรเจกต์อื่น ให้รัน `supabase-setup.sql`, `supabase-round-history.sql`, `supabase-contestant-settings.sql` และ `supabase-round-management.sql` ตามลำดับ ลิงก์แชร์เป็น bearer link: ผู้ที่ได้รับลิงก์สามารถดูผลของกิจกรรมนั้นและรอบก่อนหน้าได้ แต่ลิงก์ไม่มีสิทธิ์เขียนหรือลบข้อมูล

การอ่านและส่งออก Excel ใช้ SheetJS จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต
